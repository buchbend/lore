**2026-11-10** · Christof Buchbender · buchbend/lore#578

**Why:** SessionStart cut its text at 5,000 characters. On 2026-11-10 a session received a handover note cut in the middle, and the index after the note did not arrive. Lore had already archived the note. [#575](https://github.com/buchbend/lore/issues/575) (deliver the SessionStart text whole) asked for a text that arrives complete.

**What we did:** [PR #578](https://github.com/buchbend/lore/pull/578) (deliver the SessionStart text whole and point to the handover note) removes the cut. SessionStart now injects the path of the handover note, not the note text. A path costs one line, so a note can be as long as the work needs. The directive block shrinks from 1,111 to 695 characters. The detail moved to `lore style show filing`.

**Consequences:**
- Users: after `/clear` or compaction the agent reads the handover note from its file. A note has no size limit.
- Users: the text for the model holds no "Last active" and no "Branches" line. The status line keeps the last active day.
- Users: a scope that names a missing wiki gets a banner line that names the scope and the wiki.
- The person who onboards a repo: the scaffold writes a shorter reading rule into `AGENTS.md`.
