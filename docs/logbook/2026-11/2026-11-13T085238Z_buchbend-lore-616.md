**2026-11-13** · Christof Buchbender · buchbend/lore#616

**Why:** Issue [#616](https://github.com/buchbend/lore/issues/616) (let inbox commit with lore wiki commit): `/lore:inbox` committed each note with raw git. The note got no check and no push, so it reached the remote only at the next SessionStart.

**What we did:** Step 5 of the inbox skill now runs `lore wiki commit <path>` per note, with an action for each exit code. The skill archives the original only after exit 0. On a merge conflict or a failed push the original stays in the inbox. The note is then not safe on the remote.

**Consequences:**
- Users: an inbox note gets the same check, commit and push as a wiki entry.
- Users: a wiki folder that is no git repo now gets `git init` from the command.
- Nobody outside this repo notices.

- Not yet checked: a real inbox run against a team wiki with a remote.
