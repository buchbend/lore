**2026-11-18** · Christof Buchbender · buchbend/lore#652

**Why:** The reviews of epic #644 (larger epics and code mode) left three gaps. The intent pack dropped the focus docs of a branch, and old docs could rank first. Nothing checked the `Lenses` column. `after-merge` lost the board when a GitHub call failed.

**What we did:**
- The context pack with an intent holds the focus docs first. A superseded ADR or a shipped PRD ranks below every current doc.
- The build-order validator checks that each lens is one lowercase word. `validate-build-order --json` prints the lenses of each row.
- `after-merge` prints the board before the GitHub calls and reuses the board and ledger parsers.
- Lens reviews have their own stage tag, `build:lens-review`. The ADR check reads the status line and the `## Status` section only.

**Consequences:**
- Users: the brief of a branch keeps its own PRD. Old decisions sink in the ranking.
- The epic lead gets the board back even when a close call fails.
