**2026-11-11** · Christof Buchbender · buchbend/lore#594

**Why:** [PR #593](https://github.com/buchbend/lore/pull/593) (one plugin: merge lore-workflow into lore) left one stale picture. The architecture figure in the root README still showed the label `lore-workflow`. The repo held the SVG only, so nobody could redraw the figure.

**What we did:** The script that draws the figure now lives in the repo as `tools/fig_architecture.py`. The script is a copy from the ADASS 2026 talk folder, not a new drawing, because the copy keeps the layout the README reader knows. The script sets a fixed salt for the SVG ids and writes no date, so a second run gives the same bytes. The review found a second stale text: the figure said a session starts with at most 5,000 characters. The code limit is 10,000 (`HOOK_LIMIT_CHARS` in `lib/lore_core/session_start.py`). The figure now says 10,000. [PR #594](https://github.com/buchbend/lore/pull/594) (redraw the architecture figure with one plugin) holds the changes.

**Consequences:**
- A reader of the README sees `lore skills` and the 10,000 character limit.
- A contributor who changes the figure edits the script and runs `python3 tools/fig_architecture.py`. The script needs matplotlib.
- Users of the plugin notice nothing. The PR carries no version bump.
