**2026-11-12** · Christof Buchbender · buchbend/lore#606

**Why:** `lib/lore_core/schema.py` held three field tables. PR [#603](https://github.com/buchbend/lore/pull/603) (replace `lore wiki lint` with `lore wiki check`) removed their only reader. A table without a reader drifts and misleads the next person who writes a note.

**What we did:** We deleted `REQUIRED_FIELDS`, `OPTIONAL_FIELDS` and `required_fields_for`, and the package export. We kept `SCHEMA_VERSION` and `parse_frontmatter`, because code reads both. We did not keep the tables for [#601](https://github.com/buchbend/lore/issues/601) (let an agent write a wiki entry): that feature needs only `description`, and `lore wiki check` enforces it.

**Consequences:**
- Users and admins: nobody notices.
- Developers: `from lore_core import REQUIRED_FIELDS` now fails. No code in this repo did that.
