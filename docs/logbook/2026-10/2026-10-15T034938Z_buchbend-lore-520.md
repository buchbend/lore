**2026-10-15** · Christof Buchbender · buchbend/lore#520

**Why:** [#513](https://github.com/buchbend/lore/pull/513) (rename the epic feature table to build order) kept `lore workflow validate-roadmap` as a hidden alias. An older plugin cache still calls the old name. The alias gave no hint that the name is old. Meanwhile `lore roadmap add` uses the word "roadmap" for the `ROADMAP.md` file ([#516](https://github.com/buchbend/lore/issues/516), deprecation line from the alias).

**What we did:** The alias writes one line on stderr that names `validate-build-order`. The command reads the typed name from the Typer context. We kept one function, not a second wrapper, so both names run the same code. Stdout and exit codes stay identical, so a parser that reads `--json` sees no change.

**Consequences:**
- A person or an old skill that runs `validate-roadmap` sees the new name on stderr.
- Nobody outside this repo notices otherwise.

**Not done yet:**
- Not yet checked: when every installed plugin cache calls the new name, so the alias can go.
